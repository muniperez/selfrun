Workspaces and deployments

Browser workspaces

Use T3 Code to work with a coding agent and terminal in your browser. The dashboard opens app previews. You can stop the primary VM and resume with your files and sessions intact.

Application hosting

Deploy a web app, private API, and worker together or update them separately. Add HTTPS domains to public services and check deployment status and service logs.

First deployment guide ↗

How MiniCloud runs

The dashboard, API, and deployment worker run on a dedicated VPS. MiniCloud provisions separate machines in your Hetzner, DigitalOcean, or Vultr account to run app services and coding workspaces. The workspace gateway connects your browser to the coding VM.

  • PostgreSQL
  • OpenBao
  • OpenTelemetry
