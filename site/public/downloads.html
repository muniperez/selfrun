Download the CLI

Standalone test builds for macOS, Windows, and Linux—no Git, Python, or .NET SDK required.

Note: Unsigned test builds with embedded server source for selfrun seed.
  • macOS · Apple silicon osx-arm64 · .tar.gz
  • Windows · x64 win-x64 · .zip
  • Linux · x64 (glibc) linux-x64 · .tar.gz
  • Linux · ARM64 (glibc) linux-arm64 · .tar.gz

Install

Extract the archive, put selfrun (selfrun.exe on Windows) on your PATH, then continue with step 1 (bootstrap) or step 2 (sign in).

selfrun --version
selfrun seed

Prefer building locally with Git and the .NET 10 SDK? See publish from a clone and CLI distribution.
